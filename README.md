# Myntra Clone 👕🛍️

A modern e-commerce fashion website inspired by Myntra, built using React JS. This project provides a responsive user interface for browsing products, viewing product details, managing a shopping cart, and simulating an online shopping experience.

## 🚀 Features

- Responsive and modern UI
- Home page with featured products
- Product listing page
- Product detail page
- Category-based filtering
- Search functionality
- Add to Cart functionality
- Cart management (increase/decrease quantity)
- Price calculation
- React Router for navigation
- State management using React Hooks
- Mobile-friendly design

## 🛠️ Tech Stack

- React JS
- JavaScript (ES6+)
- HTML5
- CSS3
- React Router DOM
- Context API / useState
- Bootstrap / Tailwind CSS
